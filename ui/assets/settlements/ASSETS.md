# Settlement scene art

These are original, non-authoritative scene backgrounds generated with the built-in image generation tool on 2026-09-23. The user-provided *Lunatic Dawn: Passage of the Book* screenshots informed the **windowed interface composition**, not the imagery or game rules. Text, location, quests, prices and character state remain Godot-rendered projections.

| File | Visual brief |
| --- | --- |
| `gray_valley_scene.png` | Isometric, lived-in scrap and industrial settlement, workshops, tanks, gate, market awnings, dry hills; no UI or characters. |
| `dry_well_scene.png` | Isometric, water-scarce desert town around a deep well and fuel station; no UI or characters. |
| `new_hope_scene.png` | Isometric, reclaimed agricultural settlement with irrigation, greenhouses and water tower; no UI or characters. |

Generated with `image_gen` in built-in mode. Each prompt requested an original 16:9 hand-painted late-1990s computer-RPG scene with distinct explorable locations and expressly excluded window frames, text, labels, map markers, people, monsters and logos. Source PNGs were copied into this directory; no screenshot of the reference game was used as an edit target.
