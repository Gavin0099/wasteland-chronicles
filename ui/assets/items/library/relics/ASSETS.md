# 舊世物品、成長物、奇物與獨特物美術

本目錄保存物品世界 V0 第 12–15 類的原創透明 PNG 候選。
產圖依據為 `docs/item-world-v0.md`，視覺依循 Survivor PDA skill。

- 第 12 類：16 件舊世物品。
- 第 13 類：8 件特殊成長物品。
- 第 14 類：10 件奇物／異常物。
- 第 15 類：5 件帶有歷史的獨特物品。

`prompts.json` 保存內建 `image_gen` 的逐件提示詞；`records/` 保存生成來源、
原圖 SHA-256、尺寸與 alpha 證據。`manifest.json` 為本組 39 件的完整彙總。
PNG 複製自原始輸出，不經離線改圖。
根圖庫的 `catalogue.json` 與圖集列出實際完成範圍。

這些是背包物品圖，不代表已加入庫存、交易、掉落、鑑定、閱讀、植入或技能成長。
物品名稱、用途與可用動作應由正式 UI 呈現，圖片不烘焙敘事文字。
奇物僅以材質和形狀提供可觀察外觀，不用光暈或符文替尚未定義的世界性質下結論。
獨特槍械保留實用構造和修補痕跡，不暗示較高傷害或已實作手持動畫。

## 本組驗收

2026-09-22：39 件皆已由內建 `image_gen` 生成並保存；每件為 1254×1254 RGBA PNG，
alpha 範圍 0–255 且主體範圍非空，專案檔案與原始生成輸出逐位元組相同。
逐件檢視原圖：主體完整，紙本與卡片不烘焙敘事文字；奇物無光暈、符文或場景背景。
無影玻璃有清楚厚邊和可見玻璃本體，不是全透明空圖。

相機鏡頭保留物理刻度數字；肌纖維刺激器保留少量實體旋鈕標示；
六十三號保留鉚釘銅牌上的 `63`。這些是物件表面固定細節，不是 UI 名稱、數量或動作資訊。
縮圖名稱仍由 UI 顯示；本組不宣稱正式 Inventory 整合或可操作玩法已驗收。
