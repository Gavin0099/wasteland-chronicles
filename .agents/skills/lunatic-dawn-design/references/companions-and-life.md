# 夥伴、時間與人生

## 夥伴：改變隊伍能做什麼，不是 +20% 傷害

在廢土裡，多一個人就是：

- 多一張嘴：多耗水和食物。
- 多一份負重：能帶更多貨。
- 多一組能力：隊伍能做的事變了。

例如：
- 帶技師：拆得開你不會拆的殘骸或門。
- 帶打手：重裝掠奪者比較敢打。
- 帶嚮導：長途路線的補給成本下降。

俠客遊裡夥伴有自己的願望，完成願望才建立信任；相處久了會發展關係。夥伴的價值在於「我跟誰一起經歷過什麼」。

## 時間與人生：有，但最後才做

老化、婚姻、孩子、傳承是俠客遊很有特色的長線內容，但它們本身不會自動變好玩。它們必須建立在「角色、夥伴、世界、資源都已經值得在乎」之上。

一次引入它們，等於同時要：老化、NPC 關係、夥伴持續存在、住處、婚姻、生子、繼承、死亡後換角、裝備與世界記憶的轉移。這已經是一整個 Roguelite Legacy 階段。

## 建議的順序

```
工作讓生活成立（三種工作玩法不同）
  → 世界有想要的東西（秘密地點、常駐目標、傳聞）
    → 工作可以偏離，世界記得（地方信任、背叛）
      → 試玩證明「沒有主線也知道下一步想做什麼」
        → 夥伴（多一張嘴、多一組能力）
          → 年齡／家庭／傳承
```

在前一層還沒有被試玩證明之前加下一層，只會把不好玩的 loop 變成兩個人一起跑、或一輩子一直跑。

## 時間壓力的輕量版本

在正式的老化之前，時間壓力可以先來自：工作期限、補給消耗、城鎮狀態隨時間變化、背叛的記憶期。它們已經讓「現在做什麼」有重量。

## 反例

- 先做人生模擬的外殼（結婚按鈕、小孩頭像），但世界裡沒有值得在乎的人。
- 夥伴只是戰鬥數值加成。
- 老化只是扣屬性的計時器。
