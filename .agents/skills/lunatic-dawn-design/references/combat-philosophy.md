# 戰鬥的角色

## 戰鬥是為了目的付出的代價

- 玩家為了目的而戰（懸賞、進入某個地方、保住貨物），不是為了戰鬥獎勵去找東西打。
- 要有合理的避戰時機：付錢、談判、逃跑、繞路。它們各自要有成本（錢、一天、補給、懸賞不算數）。
- 不能談判的敵人（野犬、重裝掠奪者）要在選項上直接反映，不要給一個一定失敗的「談判」。

## 不要照抄「戰鬥沒有經驗」

俠客遊二代戰鬥後沒有報酬，要學的是「戰鬥是代價，不是刷怪主循環」，不是一定要刪掉所有戰鬥經驗。本專案的做法：第一次勝利一生只給一次 XP，懸賞的 XP 來自完成工作。這樣沒有刷怪問題，就保持原樣。

## 敵人是「晚點回來」的理由

一個現在打不過、但算得出來以後打得過的敵人，比多五種敵人更有價值。它要：

- 在戰前就能讀出危險（懸賞板的判斷、DEATH_TESTED 的精確預測）。
- 有清楚的成長解法（格鬥 +1、換一把武器、準備防禦）。
- 固定在世界上的某個地方，玩家可以選擇什麼時候去找他。

## 戰鬥可讀性

戰鬥如果只是看數字往下掉，玩家不是在決策。最小但最有效的改善：

- 敵人**下一步做什麼**、**會造成多少傷害**，直接顯示在敵人血條下面。
- 同時標出兩個選擇的後果：防禦後承受多少；攻擊能不能在他出手前打倒他。
- 顯示的數字就是實際結果（決定論下做得到，要用測試守住）。
- 顯示的是招式本身的傷害；如果因為某些規則實際扣得比較少，另外說明（「會把你擊倒」），不要讓兩個數字互相矛盾。
- 武器要真的握在手上。人物的裝備沒裝好，玩家會直接覺得「戰鬥沒做好」。

## 反例

- 戰鬥成為所有問題的預設答案。
- 每隻敵人都給 XP，於是玩家開始刷。
- 用更多動畫、更多敵人去解決「戰鬥沒有決策」的問題。
