# 成長與慾望

## 最有感的成長：「以前不能做，現在能做」

數值從 25 變 30 不會被記住。被記住的是：那扇門我以前打不開，現在打得開；那個人我以前打不過，現在打得過。所以每一種成長，都要找到至少一件它會解鎖的具體事情。

## 能力門檻要「看得到」

- 做不到的選項要**顯示並上鎖，寫明需要什麼**（「需要：機械 2」），而不是藏起來。看得到的鎖教會玩家哪個能力值得練；看不到的鎖什麼也沒教。
- 「現在不行」要讀得出來。不一定要給數字，但至少要說清楚：「照你現在的身手，正面打多半會被打倒」。
- 門檻不能只擋在 UI：engine 授權層也要拒絕。

## 慾望的來源是世界，不是清單

- **不要做成就清單**：「☐ 打倒掠奪者」「☐ 機械 5」會把自由變成 Ubisoft checklist。
- 用**傳聞**：玩家在某個鎮聽說了什麼，只有世界上真的存在的東西才會出現；每條傳聞說明「你現在還差什麼」；由玩家自己選要追哪一條。
- 追尋中的目標要一直看得到（主畫面一行字就夠）。
- 了結由世界判定（那個人被打倒了、那個地方被搬空了），不是計數器跳到 100%。

## 錢要能變成成長

俠客遊二代裡屬性要花錢訓練，賺錢和變強直接綁在一起。如果錢只能買少數幾樣東西，買完之後賺錢就失去意義。設計時問：玩家下一筆錢想花在哪？如果答不出來，就是缺了一條「錢 → 成長」的出口（訓練、裝備、通行、生活條件）。

## 不同的人走不同的路

不同背景、技能組合，應該讓不同的東西先變得可及。例如修理技工一開始就打得開軍械庫的門，拾荒者要先練。這讓「我是誰」影響「我先去哪」，而不只是數值高低。

## 一條完整的慾望鏈（本專案實例）

```
常駐懸賞：重裝掠奪者（板子直說「現在打不贏」）
  └ 懸賞說明提到：營地再過去有座軍械庫
      └ 傳聞：門要機械 2 才拆得開，你現在是 0
          └ 去練機械（工作、升級、加點）
              └ 拿到舊世軍刀（+5，哪裡都買不到）
                  └ 回去打掠奪者
```

設計新東西時，檢查它能不能接進這樣的鏈，或開出一條新鏈。孤立的獎勵不會產生「我想……」。

## 反例

- 所有成長都只是數值增加，沒有任何事情因此變得可能。
- 把長期目標做成 UI 指派的「人生任務 1/10」。
- 門檻隱藏起來，玩家不知道自己差什麼。
- 獎勵可以在市場直接買到，長途冒險就失去理由。
