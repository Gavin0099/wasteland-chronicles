# 八大支柱與核心

這裡指台灣玩家熟悉的 Artdink《俠客遊 / Lunatic Dawn》系列，特別是《Lunatic Dawn 2》的自由冒險結構。

它特別的地方不是戰鬥、不是任務數量，也不是地圖很大，而是：

> 遊戲不告訴玩家該成為誰，而是先建立一個有工作、有能力差距、有稀有事物、有人際關係與時間流逝的世界，讓玩家自己產生「我下一步想做什麼」。

## 1. 沒有唯一主線，玩家自己決定人生目標

不以「打倒魔王」為唯一終點。玩家持續接工作、賺錢、訓練、旅行、找裝備、發展關係。驅動玩家的是自己產生的目標：想變強、想學絕招、想找稀有武器、想累積財富、想組理想隊伍、想成家，或只是想成為某種人。

樂趣不是「下一個 Quest Marker 在哪」，而是「我現在最想追哪件事」。

## 2. 委託是生活來源，不是主線劇情節點

工作代表不同的生活方式：送貨是在算路程與時間，討伐是在評估戰力，護衛是在承擔風險，奪回與尋物是在探索。玩家不一定只能乖乖完成：委託物可以轉賣、私吞、延遲，而世界會因此產生後果。

好玩的是「接不接、怎麼做、值不值得照規矩做」，不只是按下完成。詳見 [quest-design.md](quest-design.md)。

## 3. 世界裡有「現在看得到，但還做不到」的東西

特定高手、絕招、稀有裝備、特殊地點，讓玩家形成長期記憶：我知道那裡有東西，但目前能力不足。於是工作、賺錢、訓練不再是抽象成長，而是為某個具體慾望服務。

不是內容鎖住玩家，而是玩家自己想回來挑戰。詳見 [progression-and-aspiration.md](progression-and-aspiration.md)。

## 4. 旅行不是內容本身，而是追求目標的成本

移動很多，但玩家通常知道自己為什麼要走那麼遠：交貨、找高手、找裝備、接高報酬工作、找特定人物。終點有玩家真正想要的東西，路程就變成準備與風險管理；終點只有另一個功能相同的城鎮，旅行就變成單純走來走去。詳見 [travel-and-world.md](travel-and-world.md)。

## 5. 戰鬥主要是代價與阻礙，不是刷怪主循環

戰鬥阻止玩家輕易得到想要的東西，或是完成特定工作的手段。玩家會衡量「這場值得打嗎？」，而不是把敵人當 XP 包。逃跑、避戰、準備裝備、挑工作因此都有意義。詳見 [combat-philosophy.md](combat-philosophy.md)。

## 6. 賺錢、工作、成長彼此相連

錢能轉換成訓練、裝備、旅行能力、生活條件。自然的經濟循環是：想變強 → 需要錢 → 挑工作 → 承擔風險 → 得到收入 → 把錢投入下一個目標。工作系統同時也是成長系統的一部分。

## 7. 夥伴不是戰鬥寵物，而是人生的一部分

組隊、長期相處、關係發展，甚至婚姻與下一代，讓角色不是孤立的數值載體。夥伴改變隊伍能做什麼，也讓玩家對「這群人」產生故事。玩家記得的不只是完成哪些任務，而是「我跟誰一起經歷過什麼」。詳見 [companions-and-life.md](companions-and-life.md)。

## 8. 時間會前進，人生不是無限最佳化

角色會老、人生有階段，不能永遠停在最佳狀態把內容清乾淨。選擇因此有重量：現在要訓練、賺錢、旅行、建立關係，還是追某件稀有物？它形成的是「人生感」，而不是把 checklist 全部勾完。

## 補充支柱：資訊本身就是進度

原作裡玩家往往是先**聽說**某處有高手、某處有寶物，才決定出發。知道什麼、不知道什麼，本身就是一種能力差距。好的設計會讓情報成為慾望的起點（傳聞、委託說明裡的一句話、地圖上的「？」），而不是一開始就把所有東西攤在 UI 上。

## 核心 Loop

> 看到一個自己想要但目前拿不到的東西 → 接工作賺錢與累積能力 → 在旅行與風險中成長 → 終於做到以前做不到的事 → 世界又出現新的慾望與人生選擇。

不是：接任務 → 跑地圖 → 戰鬥 → 領 XP → 接下一個任務。

## 四個字：自由、慾望、代價、人生

- **自由**不是按鈕很多，而是不同人生方向都合理。
- **慾望**不是系統叫你做，而是玩家自己說「我想要那個」。
- **代價**代表每條路都有成本：時間、金錢、戰鬥、生存、關係、機會。
- **人生**是角色不是一台永遠不變的解任務機器：會變強、認識人、選擇道路、老去，留下自己的經歷。

## 原作機制事實（《Lunatic Dawn 2》，供設計時引用，不是要照抄）

- 沒有傳統最終目標；接工作、賺錢、訓練，一直生活到角色老死。
- 旅店委託十餘種：送貨（錢少但安全，可把貨轉賣賺更多）、護衛（要準備食物）、擊退（難、報酬高）、奪回／救援（可直接轉賣獲利）、強盜（之後數年無法與那間店交易）等。
- 逾期回報，報酬減半。
- 戰鬥後沒有報酬，攻略建議能避則避。
- 二代沒有經驗值，屬性要花錢訓練——賺錢和變強直接綁在一起。
- 各地洞窟住著技能的「究極高手」，技能熟練度要到很高才能跟他學絕招；超級武器隨機散落在世界各處。
- 跨國移動要買通行證；各區域不同。
- 與隊員長期相處、好感夠高可以買房求婚、生子，由下一代繼續。
- 後續作品改為即時時間流逝，角色會變老。
