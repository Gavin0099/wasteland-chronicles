### 全區域宏觀收支平衡校驗 (Regional Macro Sum)
* **💧 水資源**：$+8 (\text{新希望}) - 5 (\text{灰谷}) - 3 (\text{乾井}) = \mathbf{0}$（全區淨收支完全守恆！）
* **▣ 糧食**：$+5 (\text{新希望}) - 2 (\text{灰谷}) - 3 (\text{乾井}) = \mathbf{0}$（全區淨收支完全守恆！）
* **⚙ 廢料**：$-3 (\text{新希望}) + 7 (\text{灰谷}) - 1 (\text{乾井}) = \mathbf{+3}$（微幅正向積累，支援未來維修）
* **⛽ 燃料**：$-2 (\text{新希望}) - 2 (\text{灰谷}) + 5 (\text{乾井}) = \mathbf{+1}$（微幅正向積累，支撐長程運輸）

> **結論**：三聚落沒有任何一個能單獨閉門存活。貿易不再是設計師施捨的機制，而是**物理生存的唯一解法**。

## 3. 貿易需求推導 (S1-B Trade Need Logic)

聚落不依賴擬真 AI 談判，而是透過純數學指標推導「輸出意願」與「輸入渴望」：

### 3.1 盈餘量 (Surplus) 與 赤字量 (Deficit)
對於聚落 $A$ 的任一資源 $r$：
* 當前庫存 $S_A(r)$，目標庫存 $T_A(r)$
* **赤字量（需求）**：$D_A(r) = \max(0, T_A(r) - S_A(r))$
* **盈餘量（可輸出）**：$X_A(r) = \max(0, S_A(r) - T_A(r))$

### 3.2 貿易流轉配對 (Trade Need Matching)
若聚落 $A$ 擁有盈餘 $X_A(r) > 0$，且聚落 $B$ 存在赤字 $D_B(r) > 0$：
則產生具備經濟動機的運送標的：
$$\text{TradeOpportunity}(A \to B, r) = \min(X_A(r), D_B(r))$$

## 4. 物流與商隊配置 (S1-C Logistics Network)

S1 建立覆蓋三地的三角商路，共設置 3 台常規運輸車隊：

```text
               [新希望] (水源/農業中心)
                ▲    ▲
   💧水 / ▣糧   │    │   💧水 / ▣糧
        │       │    │        │
        ▼       │    │        ▼
      ⚙廢料     │    │      ⛽燃料
               │    │
               ▼    ▼
      [灰谷] ◄──────► [乾井]
  (工業廢料中心)  ⚙廢料 / ⛽燃料  (燃料精煉中心)
```

1. **商隊 `c_hope_gray`**（新希望 $\longleftrightarrow$ 灰谷，往返 6 天）：專運 新希望的水糧 $\to$ 灰谷；折返載運 灰谷的廢料 $\to$ 新希望。
2. **商隊 `c_hope_dry`**（新希望 $\longleftrightarrow$ 乾井，往返 6 天）：專運 新希望的水糧 $\to$ 乾井；折返載運 乾井的燃料 $\to$ 新希望。
3. **商隊 `c_gray_dry`**（灰谷 $\longleftrightarrow$ 乾井，往返 6 天）：專運 灰谷的廢料 $\to$ 乾井；折返載運 乾井的燃料 $\to$ 灰谷。

## 5. 驗收標準 (S1-D Stability Acceptance Criteria)

執行完全無玩家介入的 **100 天連續模擬**，必須嚴格滿足：

1. **100 天生存不滅 (Survival)**：所有 3 個聚落在 100 天內的每一天，4 類物資庫存皆 $\ge 0$，無任何一地因飢餓或缺水崩潰為 0。
2. **無無限爆倉 (No Infinite Inflation)**：所有聚落庫存不應無限膨脹至超出合理上限（任一庫存不超過目標庫存的 3.5 倍）。
3. **價格進入合理波動帶 (Bounded Pricing)**：所有商品的即時價格在 100 天內皆維持在合法彈性範圍 $[P_{\min}, P_{\max}]$ 內，無極端失控。
4. **雙向貨流活躍 (Bilateral Flow Active)**：3 台商隊均持續在雙向航程中裝卸貨物，總貨物轉移次數 $> 30$ 次。
5. **100 天決定論回放 (Determinism)**：Day 100 快照的 SHA-256 在兩次獨立運行間完全位元一致。
