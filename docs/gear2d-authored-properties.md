工具環只減少實際攜帶工具的計重，不是任意提高容量：背包要持有且裝備才生效，主要買入、旅途拾取、換裝、卸下、存檔載入與全域容量驗證使用同一個規則（下列P2列出仍保守的舊先行檢查）。獨立正式物品背包仍是12kg；裝備工具環時最多攜帶14kg，其中豁免不能超過實際工具重量。水袋也是水專用，不能多放兩份廢料。卸包若超載須原子拒絕。

現地維修仍要滿足方法的技能、實體工具級別、場址、已接受的同一委託與期限。新增回條以明列工具 ID 綁定2廢料，保留原10／11欄回條的3廢料語義；不能把普通工具或電子工具偽造成省料來源。工具不提供技能。

各變體供應與需求為明列基底地區表：灰谷33、新希望40、乾井31件常規商品；軍用包與軍刀仍不販售。

所有效果依固定物品 ID、動作與真實裝備查表，減傷預告、實際回合及存檔重播須一致；UI 顯示 Tier、Quality、詞綴含義。全套 Godot 測試、雙軌SHA-256、全域不變量與兩種解析度畫面是交付門檻。
