# 廢土遊戲參考：物品如何成為解法

檢索日期：**2026-09-22**。狀態：**DESIGN_REFERENCE_ONLY**。

這份研究支援 185 件物品與遭遇內容的設計，不擴充已實作的 12 件
ItemDefinition，也不授權任何使用、裝備、製作、傷害或經濟效果。
每節將查證所得與本專案的原創推論分開。來源只採開發者文件、官方支援、
發行商公告與開發者本人訪談；歷史開發日誌不當作現行版本的完整規則。
以下不移植原作數值、角色、台詞、物品名稱或素材。

## WG-01 — Cataclysm: Dark Days Ahead：能力、工具與材料分開

**已查證。** 官方文件將工具的 `qualities` 與可執行操作連結；配方另行列出
技能、時間、工具與材料需求。工具能力與會消耗的材料是不同條件，
物品能提供工具能力，不代表它應在每次使用時消失。
來源：[官方 Tool Qualities 文件](https://docs.cataclysmdda.org/JSON/JSON_INFO.html#tool-qualities)、
[官方開發倉庫的製作與拆解文件](https://github.com/CleverRaven/Cataclysm-DDA/blob/master/doc/JSON/ITEM_CRAFT_AND_DISASSEMBLY.md)。

**可轉化的原創設計。** 在內容草案中，分別寫清楚「手上有什麼」、「會不會做」、
「本次消耗什麼」。例如扳手提供拆卸方案，零件是交付或替換的材料；
繩索可回收的下降方式與必須留在現場的救援方式，應是不同選擇。
這些是未來 encounter requirement 的設計資料，不是現在 tags 自帶的動作權限。

**不照搬。** 不複製龐大配方樹、工具能力等級或細部營養模型。
本次只取「同一工具能支援多種合理操作，但每個操作仍須有明確條件」的結構。
GitHub `master` 與官方文件會更新；此處未宣稱對應某個固定發行版本。

## WG-02 — Underrail：物品價值取決於誰需要它

**已查證。** 開發者在 2013-12-24 的經濟日誌說明：商人依店鋪類型與需求限制
收購種類、數量，並加入負重限制。設計理由是讓玩家挑選真正需要或有價值的物品，
減少「全部拿走、全部賣給第一個商人」成為唯一有利做法。
來源：[Stygian Software — Dev Log 25: Game Economy Changes](https://stygiansoftware.com/underrail/devlogs/25-game-economy-changes.html)。

**可轉化的原創設計。** 每件物品草案同時記錄可能的使用者與買家：
醫療袋對診所有用途，銅線對設備維護者有用途，種子對農業聚落有用途。
以「目的地有需求，但路程和貨物擠占補給」形成取捨；玩家可以留用、交付或出售。
地區供需表先是內容設計，日後才能接進本專案已有的世界經濟。

**不照搬。** 不移植原作補貨計時、價格倍率或任意收購上限。
該日誌說明的是商人需求表，不足以證明原作具有全域動態供需模擬。
也不能據此宣稱 Wasteland Chronicles 的 185 件設計物品已進入市場。

## WG-03 — Kenshi：有用的物品嵌在生活與生產關係裡

**已查證。** Lo-Fi Games 的 2016-03-31 更新紀錄把研究成本連到物品／遺物，
將發電機、燃料、風力與電池連成依賴關係，也記載旅行露營用品，以及讓交易成為
早期掠取戰利品之外的生計選項。這是當時版本的官方功能紀錄。
來源：[Lo-Fi Games — Beta Update 0.90 Released](https://lofigames.com/beta-update-0-90-released/)。

**可轉化的原創設計。** 燃料、電池、機械零件與手冊各自對應一個具體需求：
照明、維持設備、換件或理解設備。遭遇可以問玩家願不願意留下隨身電池，
換取聚落恢復一項服務；玩家保留它也必須有旅行上的理由。
普通工作與貿易品應能支撐一段人生，不必全部先轉成戰鬥獎勵。

**不照搬。** 不引入即時基地建造、整隊自動勞動或原作的研究樹。
也不從這份更新紀錄推論目前 Kenshi 的城鎮存在完整動態經濟，
或宣稱某個商品在某個地區固定有特定價差。

## WG-04 — Wasteland 3：技能讓選項成立，不保證後果最好

**已查證。** inXile 的 Brian Fargo 在官方 Xbox 訪談中說明：對話可以要求技能，
但達到高技能門檻不保證帶來好結果；世界應合理回應玩家的行為。
他也以原先打不開的箱子說明技能成長如何讓玩家回到先前的目標。
來源：[Xbox Podcast 712 — Brian Fargo 訪談與逐字稿](https://news.xbox.com/en-us/podcast/712-tell-me-why-and-wasteland-3/)。

**可轉化的原創設計。** 遭遇中的技術、社交與工具方案需要不同後果：
強行拆開可以保住零件，協商交還可以保住關係，留下原物可以保住現場證據。
技能門檻只判定能否採取方案；消耗、承諾和後續影響另寫清楚。
玩家應能理解取捨，而非把所有高技能按鈕當作免費的最佳答案。

**不照搬。** 不複製角色 build、原作任務或對話；不把「有代價」做成
無提示的隨機懲罰，也不讓敘事文字直接改世界。新後果仍須有日後明定的提交權限。

## WG-05 — Metro Exodus：裝備選擇要包含維持它的成本

**已查證。** 2019-01-22 的發行商武器公告明確介紹野外客製化，
並要求清潔、維護武器以避免過熱與卡彈。這支持「武器的使用條件不只是一個傷害值」，
沒有提供本專案可直接沿用的平衡數字。
來源：[Metro Exodus 官方 Steam 公告 — Weapons Trailer Revealed](https://store.steampowered.com/news/posts/?appids=412020&enddate=1548342020&feed=steam_community_announcements)。

**可轉化的原創設計。** 在高階槍械、探測器與照明裝備的內容欄位中，
寫下它需要哪些供應條件、在哪裡可取得支援，以及何時值得帶。
例如難找配件的裝置有特殊用途，但常見手工具在遠離聚落的路線仍有存在理由。
這是裝備角色的設計，不是現在新增卡彈或維修計算。

**不照搬。** 不啟用逐槍髒污、附件插槽、維修耗材或射擊手感系統。
本次未取得可公開閱讀的完整官方 Exodus 製作手冊，因此不把背包／工作臺的
精確配方限制寫成查證結果；亦不將其他 Metro 作品的彈藥貨幣混入 Exodus。

## WG-06 — S.T.A.L.K.E.R. 2：發現、取得與使用是三個問題

**已查證。** 官方支援說明：異常場形成的 artifact 通常需要探測器顯現；
探測器型號提供不同精度的資訊。artifact 可兼具益處與負面效果，
出售價值也與商人的態度等因素有關。
來源：[GSC Game World — Artifacts and finding them with detectors](https://support.stalker2.com/hc/en-us/articles/29871997411473-Artifacts-and-finding-them-with-detectors)
（頁面日期 2024-11-14）。

**可轉化的原創設計。** 奇物草案區分「看見的現象」、「取得它的條件」、
「已驗證的用途」與「代價」。鳴石可先是電器附近出現異聲的線索，
之後才由調查決定是否與設備有關。研究者、地方使用者與收藏者可有不同目的；
留用或交付的意義不必只剩售價高低。

**不照搬。** 不使用原作 artifact 名稱、輻射組合、探測器型號或能力數值。
未鑑定可隱藏未知用途，但玩家結算後的實際所得與消耗仍必須明確。
不能用「神祕」掩蓋尚未設計的效果，也不把裝備圖片本身當作效果存在的證據。

## 供內容表採用的六個檢查問題

下列是本專案的設計歸納，不是六款遊戲共同實作的一套規則。

| 檢查問題 | 對物品／遭遇草案的要求 | 主要參考 |
| --- | --- | --- |
| 這個物品能改變哪一種處理方式？ | 寫一個具體操作，不只寫「增加能力」 | WG-01 |
| 誰會需要它，為什麼？ | 至少一個使用者、產地或收購理由 | WG-02、WG-03 |
| 玩家為它放棄了什麼？ | 運輸負擔、耗材、時間、去向或承諾須有一項合理取捨 | WG-02、WG-05 |
| 除了動武，有沒有不同代價的解法？ | 談判、調查、交付、繞路或離開須能被看見 | WG-04 |
| 普通物品還有留下的理由嗎？ | 新裝備增加情境用途，不讓所有舊物只剩售價 | WG-01、WG-05 |
| 玩家知道的資訊夠不夠做選擇？ | 奇物可未知，但可見線索、已知成本與結算結果要分清 | WG-04、WG-06 |

本文沒有調查或證明所有列舉遊戲的所有機制，也沒有採用社群攻略的精確數值。
小說與《俠客遊：前途道標》的參考由同目錄其他研究文件分別處理。
