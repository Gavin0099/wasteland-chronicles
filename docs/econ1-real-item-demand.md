# ECON-1 — Real item demand

Risk: L2 (inventory, quest settlement and checked persistence).

The town's actual item stock now determines shortage requests. The initial scope
is the five existing recoverable workshop items (wrench, rope, flashlight,
first-aid kit, rusted knife). A town with authored demand and zero stock requests
one unit. No request is created by accepting another quest. Read-only queries
use the existing lazy seed without creating market state.

Shortage procurement is separate from ordinary workshop recovery work. Recovery
orders continue to name a genuine wreck, and buying an available item remains
legal. Authored errands retain their original origin and destination.

Requests use stable town/item/posting-window IDs and the existing accepted-job
snapshot. Replenishment removes an unaccepted offer; accepted contracts remain
honored through their deadline. Inventory held before acceptance is valid cargo.
One shortage request per item per posting window prevents immediate reward retry.

Every item delivery, including authored errands and workshop orders, transfers
the actual item into the destination market. Destination limits are checked on
detached candidates before any item or reward changes. QUEST_RESOLVED records
item stock before/after, and the delivery dialog presents that same result.
