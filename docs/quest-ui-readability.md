# 委託資訊可讀性修正

玩家完成繩索委託後回報：任務資訊容易被其他資訊擠出畫面，完成狀態也不容易找。實際畫面是右欄把委託、聚落、市集放進同一條捲軸；捲到市集後，委託標題與操作按鈕離開視野。截圖不能證明面板互相重疊，但能確認資訊層級不清楚。同一張完成畫面還有水、食物皆為 0，原警示只在左下小字出現。

參考 [ARTDINK《Lunatic Dawn: Passage of The Book》官方介紹](https://www.artdink.co.jp/japanese/title/ldpob/)中的獨立工作委託畫面，以及 [Bethesda《Fallout 76》任務 UI 說明](https://fallout.bethesda.net/ko-KR/news/fallout-76-inside-the-vault-wastelanders-quest-ui-improvements-vault-94)中「從概覽進入完整任務紀錄」的方式。本作沿用 Survivor PDA 主題，不複製它們的視覺素材或新增追蹤系統。

右欄現在有固定的「委託紀錄」入口。點開後，委託詳情佔用右欄；返回時恢復聚落／市集原來的捲動位置。頁內可切換多份委託，標題、需求、期限、持有量和報酬一起閱讀，交付按鈕留在頁底。接受委託的說明明示物品須自行取得，避免把「接任務」誤解成領取物品。完成後保留交付物與報酬的摘要；原本的即時結算對話框仍在。

水或食物歸零時，主畫面頂部顯示有文字的補給警示；左下方的低補給提示也提高至輔助文字字級。市集商品列改成兩行，讓 1152×648 視窗仍能維持地圖與右欄接近原設計比例，不需水平捲動才看得到買賣鈕。

此修正只讀既有 `PlayerUIProjection`，委託接受與交付仍走既有 Intent；沒有新增物品來源、任務後果或世界經濟連動。這是改版後的新 UI 手玩版本，不能和先前版本混作同一組「任務是否令人期待世界回應」的體驗量測。

驗證畫面：`artifacts/quest-ui-readability/` 的聚落、已捲至市集、進行中委託、完成／零補給，以及「水 0、食物 1」混合補給畫面，各有 1280×720 與 1152×648 版本。可檢查任務按鈕、買賣鈕、底部等待鍵和頂部警示均仍在畫面內；混合補給時也保留「食物 1 偏低」的獨立提示。Godot 渲染擷取腳本：`tools/capture_quest_ui_readability.gd`。
