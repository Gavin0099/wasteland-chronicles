# Battle animation references

Owner request on 2026-10-03: "沒有動畫看起來很難看 幫我找找看網路上有沒有類似的skill 或是souce code 可以參考". Research checked original repositories, concrete scripts/scenes and license files. No external code, art, audio or skill package has been installed or copied into gameplay.

The current director already translates/rotates whole standing sprites and supplies tint/damage feedback. The visible gap is articulated or frame-based attack, shooting and defeat poses. Recommendation for the authorized COMBAT-VIS-2 slice: original stance/anticipation/impact/recovery/brace/hit/fall poses, AnimationPlayer or SpriteFrames playback, then restrained receipt-driven weapon and impact effects. Idle alone will not make a swing or gun raise readable. This is a proposed implementation choice, not evidence of completed animation.
